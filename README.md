# Portafolio profesional de Delia Guadalupe Robles Galeana

Sitio web desarrollado por **Edgar Gerardo Gaytan Diaz** para presentar el perfil profesional de **Delia Guadalupe Robles Galeana**, coordinadora de Medio Ambiente y Sostenibilidad de la Red Mundial de Jóvenes Políticos.

## Acerca del proyecto

El portafolio reúne información sobre su trayectoria profesional y académica, proyectos de investigación, habilidades y medios de contacto. También incluye enlaces a sus redes profesionales y la descarga de su CV.

## Tecnologías

- [Astro](https://astro.build/)
- HTML
- CSS
- JavaScript

## Autoría

Desarrollado por **Edgar Gerardo Gaytan Diaz** para **Delia Guadalupe Robles Galeana**.
